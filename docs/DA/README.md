# Direction artistique — ACH

**Concept retenu : « Conglomérat / portail corpo diégétique ».**
ACH se présente comme un conglomérat fictif ; chaque projet est une filiale d'une
division (Jeux / Apps / Outils / Services). Registre visuel visé : **FUI megacorp
sombre** — interface de holding futuriste, dense, technique, un peu froide.

## Méthode (obligatoire, anti « look IA par défaut »)
1. **Moodboard de vraies références humaines** → à poser ici (`docs/DA/refs/`) :
   FUI de films/jeux, dashboards corpo de SF, ArtStation, Pinterest. Pas de rendu
   généré « propre » par défaut.
2. **3 pistes** déclinées (palette, typo, grille, composants) + mots-clés, à valider
   par l'utilisateur.
3. **Skin** de la page web (`web/assets/styles.css`) seulement après validation.

## Pistes de références à explorer (point de départ)
- FUI de SF : interfaces de *The Expanse*, *Alien*/Weyland-Yutani, *Oblivion*,
  *Blade Runner 2049*, Hyperion/*Borderlands*, Abstergo (*Assassin's Creed*).
- Dashboards « holding / division » : org-charts, écrans de supervision, monospace
  technique, numéros de série, codes de division.
- Studios FUI réels (mots-clés recherche) : « FUI », « HUD design », « sci-fi
  interface », « corporate dystopia UI », « operations console ».
